# The candidate's test stack for stage 3, hash-pinned.
#
# This is not the library's dependency list -- zlib has none, and the Java port is
# expected to have none either -- it is what a candidate test file is allowed to
# import beyond the standard library and srbzlib.  Both trees get the same versions
# from the same venv, because a candidate whose pytest differed between the two
# halves of a comparison would not be comparing the two implementations.
#
# The same five versions lang01's stage 3 pins, for the same reason: a benchmark
# should not run two pytests.  Python here is 3.11, so neither exceptiongroup nor
# tomli is in the closure.
#
# Deliberately absent, and each for its own reason:
#
#   zlib-anything   A candidate that imported a third-party zlib binding would be
#                   comparing the submission against that, not against the
#                   original.  The original is in the container and is what the
#                   comparison is against.
#   httpx, requests Nothing here speaks a protocol.  A candidate reaches both
#                   libraries through srbzlib -- probe ops, and the two upstream
#                   driver programs from the build directory.
#   hypothesis      Property generation whose corpus depends on a seed nobody
#                   pinned makes a break irreproducible, and the adjudicator
#                   reruns every candidate three times and requires identical
#                   results.  A candidate that wants random input generates it
#                   from a seed it writes down.
#
# Python's own `zlib` module is in the standard library and cannot be removed. It
# is not a hazard: a candidate that compares the submission against CPython's
# bundled zlib rather than against the original tree has written a test that
# measures nothing the stage asks about, and the adjudicator's requirement that a
# candidate PASS on the original is what rejects it -- CPython's zlib is not this
# task's oracle and does not agree with State A's on the surfaces that matter.
