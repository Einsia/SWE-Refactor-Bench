# The scan's runner, and nothing else.

# Four packages, hash-pinned, --no-deps: this is a test runner for ~1,880 checks
# that open files and hash them.  Nothing here can import or execute the
# submission, and that is the point of keeping the list this short -- the moment a
# subprocess helper or a wasm runtime binding appears in this image, a scan module
# could run the port, and stage 1's whole claim is that it cannot.
#

# programs that write the result envelope directly, because a case set of 2,653
# differential comparisons is not a collection of test functions -- so unlike the
# other tasks there is no second requirements file to keep these in step with.
# The versions are the benchmark's standard pins.
