# What a candidate may import, at one set of versions for both trees.
#
# Five packages, hash-pinned, --no-deps -- the same five and the same versions as
# tests/behavioural/requirements-runner.txt, so there is one runner version to
# reason about across the three stages. A candidate that ran under pytest 7 on one
# tree and pytest 8 on the other would not be comparing the two applications.
#
# There is no HTTP client here, and that is the design rather than an omission. A
# candidate does not speak to the application over HTTP: it declares a scenario in
# stage 2's own vocabulary, and lib/srbprobe.py drives a real browser at the build
# and hands back the same normalised observation stage 2 compares. Handing a
# candidate a base URL would hand it the bundle's bytes, and with them the identity
# of the tree it is on -- which probe.toml denies and the adjudicator rejects on
# sight. Removing the capability is better than forbidding it.
#
# The driver itself needs nothing from this list. srbprobe is stdlib-only, and the
# browser side is Node: Playwright is installed at /opt by the Dockerfile, at the
# same version stage 2 drives with.
