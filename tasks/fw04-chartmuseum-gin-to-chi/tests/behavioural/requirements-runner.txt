# The stage's own Python stack, hash-pinned.
#
# Deliberately tiny.  The suite drives the submission over real HTTP using the
# standard library only (http.client), so nothing here can drift into the
# behaviour being graded: no httpx, no requests, no plugins beyond a timeout.
# The submission is a Go binary and the toolchain that builds it is the image's
# Go, not anything on this list -- so unlike a Python task, this file has no
# overlap at all with what the graded program depends on.
#
# PyYAML is the one addition over the minimum, and it is not optional: an
# index.yaml has to be compared as a parsed document as well as as text, so that
# a failure can name the entry and field that moved instead of printing a diff of
# two 40-line YAML blobs.  It is pinned to the exact version the construction-time
# capture used, because the capture parsed the same bytes -- a version skew
# between the two would surface as a semantic diff in an index that never
# changed.
#
# tests/audit/requirements-scan.txt pins the same versions of the
# packages it shares with this list, so both stages run the same pytest and there
# is one version of the runner to reason about across the tree.
#
# Installed with --require-hashes, so a substituted artefact fails the build.
