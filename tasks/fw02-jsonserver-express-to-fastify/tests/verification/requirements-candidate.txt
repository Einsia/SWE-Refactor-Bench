# The candidate's test stack for stage 3, one set of versions for both trees.
#
# This is not the service's dependency list -- the service is Node, and its two
# possible closures are lock-baseline.json and lock-target.json in data/. This is
# what a candidate test file is allowed to import beyond the standard library.
#
# The same pytest and pytest-timeout the other stage 3 images pin, and the same
# ones stage 2's grader uses: a benchmark should not run two pytests, and a
# candidate whose pytest differed between the two halves of a comparison would not
# be comparing the two frameworks.
#
# Deliberately absent: httpx, requests, aiohttp -- any HTTP client that
# decompresses a body transparently, follows a redirect on its own, or normalises
# a header dictionary. The whole subject here is bytes on the wire: the ETag
# format, the Link header's spelling, whether Content-Encoding appears, whether a
# 304 carries a body. `http.client` shows a candidate exactly what arrived, and
# stage 2 measures 369 recorded exchanges through the same standard library, so
# there is nothing a candidate needs that it does not have.
#
# Installed with --require-hashes, so a substituted artefact fails the build.
