# The stage's own Python stack, hash-pinned.
#
# Deliberately tiny.  The suite drives the submission over real HTTP using raw
# sockets from the standard library -- `harness.wire` assembles the request line
# byte for byte -- so nothing here can drift into the behaviour being graded.  No
# httpx, no requests, not even http.client: every convenience client normalises a
# target, and the most informative case in this corpus (`GET /files/sub%2Fb.txt`,
# which the retired router answers 200 and a naive port answers 404) is destroyed
# by any client that rewrites what it was given.
#
# No PyYAML, unlike the Helm task's list.  This repository's only YAML is its CI
# workflow, and what that workflow claims about the build is checked by this stage
# doing the build.
#
# pytest-timeout is the one addition over the minimum, and it is not optional.
# Every request is a blocking read on a raw socket, and a submission that accepts
# a connection and never answers would otherwise hang the module until the
# suite-level timeout killed it -- losing the other 86 cases along with the one
# that hung.
#
# The submission is a Go binary and the toolchain that builds it is the image's
# Go, not anything on this list, so unlike a Python task this file has no overlap
# at all with what the graded program depends on.
#
# tests/audit/requirements-scan.txt pins the same versions of the four
# packages it shares with this list, so both stages run the same pytest and there
# is one version of the runner to reason about across the tree.
#
# Installed with --require-hashes, so a substituted artefact fails the build.
