# The interpreter a candidate runs in, and nothing else.
#
# pytest because a candidate is a test file and its PASS/FAIL is the signal the
# adjudicator reads. pytest-timeout because a candidate that hangs must fail as a
# candidate rather than take the round's whole budget with it -- run-candidate.sh
# passes --timeout=2100 against the harness's 2400s ceiling, so the inner limit
# always fires first and the failure is attributable.
#
# Same pytest version as stages 1 and 2. Collection behaviour decides what counts
# as a test, and a stage that drifted onto a different runner could disagree with
# the other two about whether a candidate collected at all.
#
# Deliberately absent: any HTTP client, any archive library beyond the standard
# library's zipfile, any JVM bridge. The image has no network. lib/srbgson.py,
# lib/jarinspect.py and lib/classfile.py read jars, class files and JUnit XML with
# zipfile, struct and re, which is also why a malformed entry surfaces as the
# defect it is instead of being tolerated by something more forgiving.
