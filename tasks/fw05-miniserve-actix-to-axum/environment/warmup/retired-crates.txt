# These crate names are omitted from the DELIVERY local-registry, so cargo
# cannot resolve them at all: `cargo build` stops with "no matching package
# named `actix-web` found". They exist only in the BASELINE registry, which is
# used once at image-build time to compile the read-only State A oracle and is
# then deleted from the image.
#
# The list is the whole actix family, not just the four crates miniserve names
# in its manifest. Banning `actix-web` alone would leave `actix-http` +
# `actix-server` + `actix-service` reachable, which is enough to rebuild a
# working actix stack by hand and would make the gate decorative.
#
# Every name here is also asserted absent from the submission's Cargo.toml,
# Cargo.lock and sources by the audit suite -- the registry stops a build,
# the scan stops a vendored copy.
# =============================================================================
