# The stack a candidate test may import, hash-pinned.
#
# Same versions as tests/behavioural/requirements-suite.txt, and that is the point
# rather than a convenience: a candidate is asked to write a test in the shape of
# a stage 2 test, so the library it writes against has to be the one stage 2
# runs.  A candidate that passed here under a different pytest would be reporting
# on a suite the benchmark does not own.
#
# Nothing beyond the standard library for HTTP, and for this task that omission
# is load-bearing rather than cautious.  Every observable the corpus grades is
# something a client library would tidy away before the test could see it:
#
#   * `requests` and `httpx` normalise the request target -- they will quote a
#     space, collapse a doubled slash and resolve a `..` before it reaches the
#     socket.  Path decoding is one of the six rounds, and `%2F` inside a
#     segment is the single most productive request in it.  A candidate that could
#     not send that byte sequence could not ask the question.
#   * They follow redirects, and `--spa`, `--pretty-urls`, `--route-prefix` and a
#     directory without its trailing slash are all redirect behaviour.
#   * They fold duplicate headers into one value, and `--header` given twice is a
#     documented flag whose whole contract is that both arrive.
#   * They decode Content-Encoding transparently, and `--compress-response` is
#     about exactly which encoding was chosen.
#   * They verify TLS, and the shipped certificate is self-signed for 127.0.0.1.
#
# `http.client` puts the request line on the wire as handed over and returns the
# headers in order with duplicates intact; `socket` is there for a request too
# malformed for even that.  lib/srbtarget.py wraps both.
#
# No archive libraries either, and that omission is not deliberate: tarfile and
# zipfile are in the standard library, which is where a candidate examining a
# generated archive should get them.
#
# pytest-timeout so a candidate that writes a request with no deadline fails its
# own round instead of consuming the stage's wall clock.  run-candidate.sh passes
# --timeout=240, which is generous because a single test may boot several servers
# and each boot waits for a port.
#
# Installed with --require-hashes into /opt/venv, so a substituted artefact fails
# the build rather than the stage.
